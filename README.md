# arxiv-fixes

This repo is meant for keeping my nontrivial changes to arXiv submissions, 
so that the source compiles and the resulting document is something I consider usable.

For info index of entries, see [here](./index.md)

`index.md` and `index.html` are generated by `scripts/generate_index.py`
from the per-paper `paper.json` metadata files; do not hand-edit them.
PDFs are build products: CI builds them with `latexmk` and deploys them
to GitHub Pages (see `plan.html`, sections 4-6).
